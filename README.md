# Personal Assets

Personal Assets 是一个适用于 Halo 2.x 的个人资产管理插件。插件可在 Halo Console 中维护资产分组和资产条目，并提供前台 `/personalassets` 页面，用于展示个人装备、设备、工具、作品资源、常用服务或其他带图片的资产清单。

本插件由图床管理插件和原装备管理插件改编而来。

## 功能特性

- 在 Halo Console 中管理资产分组。
- 为每个分组添加资产条目。
- 支持资产名称、封面、价格、规格、描述和排序。
- 支持从 Halo 附件库批量选择图片创建资产。
- 支持资产拖拽排序、批量删除和批量移动分组。
- 支持自定义资产 ID 前缀和 ID 长度。
- 支持前台是否显示价格。
- 内置前台页面 `/personalassets`，启用插件后即可访问。
- 前台资产页面支持分组筛选和资产搜索。

## 环境要求

- Halo 版本：`>= 2.22.0`
- Java 版本：`21`

## 安装使用

1. 在 Halo Console 的插件管理中上传插件 jar 包。
2. 启用 `Personal Assets` 插件。
3. 进入左侧菜单「资产」。
4. 新建资产分组。
5. 在对应分组中新增资产。
6. 访问 `/personalassets` 查看前台资产页面。

## 资产分组

资产分组用于归类展示资产，例如「在用资产」「停用资产」「电脑设备」「软件工具」「摄影器材」等。

新建分组时可填写：

- 分组名称：前台显示的分组标题。
- 分组描述：显示在分组标题下方。
- 排序值：数值越小越靠前。

前台页面会按分组排序展示资产，并在分组标题后显示当前分组的资产数量。

## 资产条目

新增资产时可维护：

- 名称：资产卡片标题。
- 封面：资产卡片顶部图片。
- 价格：开启价格显示后，会显示在资产卡片底部左侧。
- 规格：资产名称下方的简短信息。
- 描述：资产补充说明，前台最多显示三行。
- 分组：资产所属分类。
- 排序值：用于控制同分组内的展示顺序。

资产 ID 默认随机生成，也可在插件设置中配置 ID 前缀和 ID 长度。设置前缀后，前台显示格式为 `前缀-ID`。

## 前台页面

插件内置前台页面：

```text
/personalassets
```

前台页面包含：

- 页面标题和副标题。
- 资产分组筛选。
- 资产搜索。
- 四列资产卡片布局，移动端自动适配。
- 卡片封面、名称、规格、描述、价格和资产 ID。

分组筛选使用 URL 参数：

```text
/personalassets?group={groupName}
```

其中 `{groupName}` 是资产分组的 `metadata.name`，不是分组显示名称。

## 插件设置

进入 Halo Console 的插件设置页面，可调整：

| 设置项 | 说明 | 默认值 |
| --- | --- | --- |
| 页面标题 | 前台 `/personalassets` 页面的主标题 | 个人资产 |
| 副标题 | 主标题下方的一行文字 | 看得见的家底，理得清的资产。 |
| 是否开启价格显示 | 控制前台资产卡片是否显示价格 | 关闭 |
| 资产 ID 前缀 | 生成资产 ID 时使用的前缀 | 空 |
| 资产 ID 长度 | 随机资产 ID 的长度 | 6 |

## 主题兼容说明

插件默认提供独立前台模板。为了避免不同主题的布局片段差异导致 500，默认模板会读取 Halo 主菜单并在插件页面内渲染导航，再展示资产内容。

如果当前主题希望完全自定义资产页面结构，可在主题中提供 `personalassets.html` 模板。Halo 会优先使用主题模板，主题模板中可通过 Finder 名称 `personalassets` 获取资产数据并自行渲染。

## 常见问题

### `/personalassets` 页面没有资产？

请确认插件已经启用，并且已经在 Console 的「资产」页面中新建分组和资产。资产必须归属于某个分组，才会在前台分组展示中出现。

### 分组筛选后没有变化？

请确认安装的是新的插件版本。测试包和正式包版本号不同，Halo 可能会缓存同版本插件包。

分组筛选会跳转到 `/personalassets?group={groupName}`，如果 URL 没有变化，通常说明浏览器或插件包仍在使用旧版本。

## 开发构建

本项目使用 Gradle 构建：

```bash
./gradlew build
```

Windows 环境：

```powershell
.\gradlew.bat build
```

构建完成后，插件包位于：

```text
build/libs/
```
